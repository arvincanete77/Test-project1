BRBS for DJC — Browser Storage Version

START:
1. Extract the ZIP.
2. Open the folder in TrebEdit or another HTML editor, or open Login.html in a browser.
3. Choose Sign up, create an account, then log in.
4. Open Book Storage and enter ISBN, Book name, and Author, then tap Save Book.
5. Use Borrow Books to select a saved catalog book (autofills ISBN/title/author) or enter those details manually.
6. Use Return Books to search by LRN and mark selected books returned.

FEATURES:
- Local book catalog with ISBN, book name, and author.
- Add, search, edit, delete, and export the catalog to CSV.
- Borrow records and returns history.
- Dashboard counts.
- Student and Staff accounts do not see the Recent Borrowing Records card.

STORAGE AND SECURITY:
Data is saved in localStorage on the current browser/device. It does not sync across devices. Clearing browser data may erase it. This is a demo/learning project, not secure production software: passwords and records are stored in the browser and can be inspected. For actual school use, use server-side authentication and a database.
